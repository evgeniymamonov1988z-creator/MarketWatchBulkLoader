# Market Watch Bulk Loader (MetaTrader 5)

Utility (Expert Advisor) for MetaTrader 5 that quickly adds a list of tickers to the **Market Watch** window. Paste your ticker list once and the tool finds the matching broker symbols and switches them on — no manual search for each symbol.

- Does **not** trade, does **not** send orders, sends **no** data outside your terminal.
- Interface and help available in 12 languages (RU, EN, DE, ES, ZH, TR, HI, AR, FR, BN, PT, ID).

## Free 3-day trial

This repository contains the **free trial version** — full features for **3 days** from the first launch, with no symbol limit. After 3 days the loader stops adding symbols and asks for the full version.

Full (unlimited, no time limit) version: https://evgeniymamonov.com

## Install

1. Download `Market Watch Bulk Loader Trial.mq5` from [Releases](../../releases) or this repository.
2. In MetaTrader 5: **File -> Open Data Folder -> MQL5 -> Experts**, copy the file there.
3. In MetaEditor press **Compile** (F7).
4. In the terminal, drag the EA onto any chart.

## How to use

1. Press **TXT** on the panel.
2. Paste your tickers (separators: comma, space, or semicolon), e.g. `EURUSD, GBPUSD; USDJPY XAUUSD`.
3. Press **Copy** — matching broker symbols are added to Market Watch.
4. Press **?** for the multilingual instructions.
